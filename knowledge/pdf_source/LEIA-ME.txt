Coloque aqui os PDFs da documentação oficial Lenovo (ou use o script para descarregar).

1) Descarregar para esta pasta (URLs que você copia do suporte)

  Na raiz do projeto:

  python download_lenovo_pdfs.py "https://...ficheiro.pdf"

  Vários URLs de uma vez, ou a partir de um ficheiro (um URL por linha):

  python download_lenovo_pdfs.py --urls-file urls_lenovo.txt

  Opcional: abrir uma página de produto e tentar extrair links .pdf do HTML
  (nem todas as páginas expõem PDFs no HTML — muitas usam JavaScript):

  python download_lenovo_pdfs.py --page "https://pcsupport.lenovo.com/br/pt/product/..."
  python download_lenovo_pdfs.py --page "URL" --dry-run

  Respeite os termos de uso da Lenovo; não use como crawler do site inteiro.

2) Extrair texto para o RAG

  pip install pymupdf
  python extract_pdf.py knowledge/pdf_source -o knowledge/extraido_oficial.txt

3) Revisar o .txt e, se necessário, fundir em lenovo_knowledge.txt; depois:

  python ingest_chroma.py

Os ficheiros .pdf nesta pasta estão no .gitignore por omissão.
